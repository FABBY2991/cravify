# 2. One brand, five categories, one slide each

Cravify is one food brand (not a marketplace) with Burgers, Pizza, Fried
chicken, Shakes & Drinks and Desserts. Each category owns one hero slide with
its own colour, headline and featured item — the reference video's structure,
widened from milkshake flavours to a menu. The category colour doubles as the
menu-tile colour. Categories, items and slides all live in the database and
are edited in the admin; the seed is only a starting point.
